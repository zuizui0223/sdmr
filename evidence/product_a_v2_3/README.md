# Product-A v2.3 evidence boundary

This directory records the immutable unseen-known-truth decision for the
set-valued ecological-certificate experiment.

- `decision.json` is the machine-readable decision and source provenance.
- `decision.md` is the human-readable rendering of the same evidence.
- The source run uses predeclared unseen known-truth panels and freezes discovery
  candidate sets before validation truth is opened.
- This evidence may support, reject, trivialize, or mark unavailable the
  set-valued development product. Every state is a valid result.
- It is not a real-GBIF/CHELSA Product-A promotion result and does not satisfy the
  merge gate for PR #1 into `main`.
