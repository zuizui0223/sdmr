## Compression rule

The manuscript should not devote equal narrative weight to every version. Collapse the sequence into five scientific transitions:

1. **prediction/stability ≠ process recovery** — v1, v2.1, v2.2;
2. **agreement ≠ necessity** — v2.3;
3. **falsification + abstention → safe set inference** — v2.4–v2.6;
4. **determinism + fresh known truth → safe and sharp process core** — v2.7.1–v2.7.2;
5. **prospective fresh empirical test → external-validity boundary** — v2.7.3–v2.8.4.

All workflow IDs, artifact IDs, intermediate execution-recovery details and version-specific operational transitions should go to the provenance supplement unless required to explain information leakage or the distinction between technical/unavailable and scientific outcomes.
