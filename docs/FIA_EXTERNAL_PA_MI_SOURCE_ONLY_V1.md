# SDMR external geographic holdout: Pennsylvania and Michigan, source-only first opening (v1)

**Stage:** geographically disjoint **source opportunity only**. No source-matched growth, survival, physiological fitness, causal limiting factor, true niche process or predictive performance has been estimated. Existing FIA outcome analyses use RI/VA/WI; Pennsylvania (PA) and Michigan (MI) have **not** been used in those analyses. NEON is paused, no API token needed.

## Why PA and MI, and what constitutes independent evidence

The purpose of SDMR is to distinguish:
1. **Common-response/environment-opportunity null:** the same species-specific ecological response applied across regions produces apparent changes in "dominant environmental factors" because available environments, forest context and observation opportunities differ.
2. **Region-specific response alternative:** after equalizing support and observation processes, geography still requires different environment–response parameters for a given species.

A source-only external panel is fixed **before consulting tree response values** from its holdout regions: \`PA\` adjacent to historical development \`VA\`, and \`MI\` adjacent to \`WI\`. The geographic roles and the **five previously selected priority species** (\`129 Pinus strobus; 316 Acer rubrum; 802 Quercus alba; 833 Q. rubra; 837 Q. velutina\`) are not adjusted for favorable holdout performance; all 13 previously declared SPCD taxa remain in the source-only denominator. Selection of these states *after viewing existing VA/WI growth results* means the test is a **postdevelopment** holdout, not preregistered from the original research program. Different state sampling supports geographically disjoint individuals/plots; it does not mean independent evolution or causality.

## Pre-response eligibility screen (fixed in this successor)

For each of the **13 original SPCD taxa**, build training-source joint T–P–time cells using VA and WI independently: a cell qualifies in each region if represented by **≥2 distinct counties and ≥5 distinct physical plot chains**, and the intersection must contain ≥2 cells. For each holdout state PA, MI independently, count source regions, distinct counties and plot chains, and the fraction of holdout plot chains in **the training-defined intersection**. Source-readiness threshold **per species × holdout state**: ≥5 counties, ≥25 plot chains, ≥20% unique-plot coverage in training-supported time-aligned joint environmental cells. These values reuse the prior source gate; they are *not* tuned on the new outcomes. Keep a full **13×2 eligibility ledger** with explicit reasons; no favorable-species promotion after examining growth.

A passing source-only gate says that response transfer *might* be measurable. It does **not** show the response itself is stationary, whether diameter is measured compatibly, or that enough matched live trees exist in PA/MI. Refuse any biological promotion until that independent response-stage data contract is separately frozen.

## What the eventual external test would compare

The existing VA/WI observational models include state intercepts and a region-varying climate interaction, so a completely unseen PA or MI **intercept and slope cannot be estimated without data from that state**. A valid future comparison must explicitly prespecify one of:
- Predict PA using the VA-trained regional branch and MI using the WI branch versus the one shared-environment slope, with the corresponding regional intercepts frozen. These are **geography-defined surrogate transfer** predictions, not estimated PA/MI coefficients. Match both models on all nonclimate controls and the same holdout source support.
- Or reserve truly separate training and test counties *inside* PA/MI for local recalibration, predefining the calibration sample/thresholds **before** opening any PA/MI growth, then evaluate on never-used counties.

Use only prior-stage site context, actual survey design and separate all-prior-live survival outcomes from **live→live conditional growth**. Do not call absence at followup a death. An out-of-region RMSE gain (or lack thereof) is predictive evidence, **not** unique causal identification of the environmental niche. Observational noise, microclimate and stand management remain confounded.

## No-retry reproducibility boundary

\`experiments/fia_external_PA_MI_first_source_v1.py\` and focused synthetic tests implement this **strict source-only** acquisition, schema, county chain, raw SHA and joint-coverage evaluation. The one-shot GitHub Actions workflow runs only on a unique, source-fixed lock; a failed run must be preserved as a STOP, not silently rerun with new DataMart content.

The fixed analysis can emit no eligible species and still **correctly** report a completed source-only audit if both state sources are genuine. If any required raw source, baseline or original training artifact cannot be verified, it must issue \`source_unavailable_or_invalid_stop_no_biological_outcome\` and refuse any sourced biological conclusion. Existing Product A/M5, the 0/5 climate practical gain, positive spatial BA predictor results, limited temporal density-change results and blocked Product B remain unchanged.
